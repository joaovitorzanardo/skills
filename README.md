# skills

My personal repo for the Claude skills I write for myself.

## Skills

- **[baozi](baozi/)** – my life-goals agent. Helps me set and review long, mid and short-term goals, keeps track of my interests and life areas, and writes them to a goals doc in Google Drive.
- **[doudou](doudou/)** – my planning agent. Turns Baozi's goals into daily and weekly plans and Google Calendar events, handles check-ins and replanning, and logs progress in Google Drive.
- **[mvp-scope](mvp-scope/)** – cuts a product down to its MVP. Reads a `PRD.md`, sorts the features with MoSCoW and writes a `SCOPE.md` with the MVP list and a Later List.
- **[area-of-knowledge-expert](area-of-knowledge-expert/)** – maps a whole field for someone starting to learn it: its main sub-fields, real academic sources for each, an introduction with ABNT citations and an interactive visual map (`MAP.html`).
- **[teach-me](teach-me/)** – a learning accelerator for one topic. Asks why I want to learn it, runs a diagnostic quiz, writes a syllabus and builds interactive HTML lessons with cited sources and a practice section. Grades my pasted results, reteaches what didn't stick, and keeps a long-term study memory in `~/.study-memory/`.
