## Teach to Me

This skill has the goal to be a learning accelerator, i will pass as a parameter a certain topic that i want to learn and your goal is to teach me.

### 1. Clarification

Before anything else you need to understand some things about the user:

#### What's the user goal in learning about that topic?

It can be something as simple as: "Because i am interested", "I just want to review it"or it can be something more complex like "I want to build a project (describes the project) and i need to understand that concept".

#### How much the user know about it? (Evaluation)

Before creating lessons you need to understant the level of understanding of the user so u can calibrate the content of the lessosn. Generate 10 to 20 questions, most in a multiple choice style and 1 or 2 for the user to write.

This questions need to measure if the user knows the necessary fundamentals do learn the concept his trying to learn, how familiar he is with the concepts surrouding.

For example, if i am trying to learn about PCB design, you need to check first if i know about circuits, ohm's law and other fundamentals.

If the user wants to build a drone, i need first to check if he already understands about aerodynamics.

### 2. Leasson Creation

Based on the user understanding of the topic you have to create a first lesson about it. If he lacks fundamentals, add topics teaching the fundamentals or reviewn then.

- The leassons should be written in a language that is easy to understand, technical terms are still important, but reading doesn't need to be boring, it can be simple and interesting and preserving the technicality.
- You should always when possible use visual artifact and interactive visuals to help the user to understand the concept you are trying to teach, drawings, diagrams, mental models, interactive systems.
- Always use resources that are trusted in the field, relevant text books, academic papers and for newer subjects that are constantly changing, like AI, you can use other resources like blogs, youtube videos, especialy in things that requires personal preferences, like AI Workflows for example.
- Always add a practice part at the end, the practice can be a simple test with multiple choice answers, or can be a pratical exercice with a interactive systems. The results of the practice should be saved in a file called TEST_RESULTS.md.
- Add the resources at the end and alwys link to the citations in the text, like in academic work.

#### 3. Check the Learning

- Read the file TEST_RESULTS.md and evaluate the results so you can define if the user really learned what it was proposed.
- If he did, you can move to the next leasson, if he didn't u create a new leasson with the contents that were not absorved. Reapet this loop until the user learns. You can also chat with him about what he didn't understood, and give a more personal treat.
- When the user learns something new, you will register following the instruction that are in memory-retrievel.
